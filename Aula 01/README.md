**FrontEnd**
Desenvolvimento Front-end é a camada de aplicação com qual o usuario interage diretamente (interface).

**Arquitetura de um Site:**

É a organização / planta do site, utilizando de prototipação e UX. Pensando como as escolhas podem ser mais adequadas a solicitação do cliente.

**Vanilla JS**

O Vanilla JS, como diz o nome é a versão original (Vanilla) do JavaScript, composta por HTML, JavaScript e CSS. que cria um ambiente unificado de trabalho, podendo manipular paginas, se comunicar com servidores além de possuir uma logica de interface propria.
